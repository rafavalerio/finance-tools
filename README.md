# Mortgage Planner

A client-side mortgage planning tool for Australian home buyers.

## Calculator

Estimate repayments and purchase costs for properties in all Australian states and territories.

- Weekly, fortnightly, or monthly repayments
- State-specific stamp duty for standard buyers, first home buyers, and foreign buyers
- Purchase costs, including legal fees, inspections, and registration
- Lenders Mortgage Insurance estimate
- Offset account balance
- Loan amortisation chart
- Browser auto-save and shareable calculation links

The calculator is available on the home page. Mortgage inputs are saved in browser storage and can be shared through a URL. No account or backend is required.

## Tech stack

- Next.js 16 App Router, React 19, TypeScript
- Tailwind CSS v4
- Recharts and lucide-react
- Vitest and React Testing Library
